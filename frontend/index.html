Why CanteenIQ

Designed around the actual planning problem.

The interface keeps the prediction process simple while making the model inputs understandable to the person actually managing the canteen.

📅

Calendar-aware

Day, month and weekend status are derived from the selected date automatically.

🌦️

Weather signals

Temperature and rainfall are included as demand signals during prediction.

🍽️

Item-level demand

Forecast demand separately for Biryani, Chai, Dosa, Samosa and Sandwich.

📈

Historical context

Recent average demand provides a historical baseline to the trained model.

⚡

API inference

The frontend communicates with a Flask REST API for real-time model inference.

🧠

ML-powered planning

A trained regression model converts the supplied signals into an estimated food demand value.

ABOUT CANTEENIQ

Smarter demand.
Better preparation.

CanteenIQ is an end-to-end machine learning project that helps college canteens predict daily food demand using historical demand, weather, calendar and special-day data.
