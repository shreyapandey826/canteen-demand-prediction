Why CanteenIQ

Designed around the actual planning problem.

The interface keeps the prediction process simple while making the model inputs understandable to the person actually using the system.

📅

Calendar-aware

Day, month and weekend status are derived from the selected date instead of asking the user to duplicate information.

🌦️

Weather signals

Temperature and rainfall can be included as demand signals when generating the forecast.

🍽️

Item-level demand

Forecast demand separately for Biryani, Chai, Dosa, Samosa and Sandwich.

📈

Historical context

Recent average demand gives the model a historical signal instead of relying only on today's conditions.

⚡

API inference

The frontend communicates with a Flask REST API for real-time model inference.

🧠

ML-powered planning

A trained regression model converts the supplied signals into an estimated food demand value.

About the project

From prediction to preparation.

CanteenIQ is an end-to-end machine learning project built to explore how historical demand and everyday conditions can support more informed food preparation in a college canteen.
